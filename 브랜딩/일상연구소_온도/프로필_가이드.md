# 일상연구소 온도

생활을 가볍게 만드는 작은 정보를 기록하는 라이프스타일 콘텐츠 프로필입니다. 금융·카드·소액결제 콘텐츠로 확장하더라도 첫인상은 생활 정보 채널로 유지합니다.

## 프로필 기본값

- 표시 이름: **일상연구소 온도**
- 영문 보조명: **DAILY ONDO LAB**
- 핸들 후보: `@daily.ondo` / `@ondo.lab` / `@dailyondolab`
- 카테고리: 라이프스타일 · 생활정보
- 한 줄 소개: **오늘을 조금 가볍게 만드는 생활 정보**
- 소개 문구: **결제·절약·일상 팁을 어렵지 않게 정리합니다. 필요한 순간 꺼내 보는 현실적인 체크리스트.**
- 문의 문구: **콘텐츠 제휴·문의는 DM**
- 슬로건: **알아두면 생활의 온도가 달라집니다.**

핸들은 플랫폼별 실제 사용 가능 여부를 확인한 뒤 확정합니다.

## 에셋

- `assets/profile-avatar-natural.webp`: 960×960 자연광 프로필 이미지
- `assets/profile-cover-natural.webp`: 1800×720 자연광 커버 이미지

프로필명과 슬로건은 이미지에 직접 굽지 않고 플랫폼 텍스트 또는 별도 오버레이로 사용합니다. 이미지는 실제 촬영에 가까운 자연광 스타일로 제작한 뒤 웹용으로 리사이즈·압축했습니다.

## 콘텐츠 방향

1. 생활비와 결제 습관
2. 카드·간편결제 사용 팁
3. 급할 때 확인할 체크리스트
4. 사기·피싱 예방 정보
5. 생활 서비스 비교와 선택 기준

금융 광고처럼 보이는 표현보다 “오늘 바로 써먹는 생활 정보”의 문장 구조를 우선합니다. 대출·고수익·즉시 현금 같은 직접적인 후킹은 피하고, 실제 조건과 유의사항을 함께 적습니다.

## 첫 9개 게시물 주제

1. 이번 달 고정비 10분 점검표
2. 카드 결제일 전에 확인할 세 가지
3. 간편결제 알림을 켜야 하는 이유
4. 생활비 새는 구독 서비스 찾기
5. 급한 결제 전 체크리스트
6. 오픈채팅 사칭 계정 구분법
7. 수수료 안내에서 꼭 볼 문장
8. 신용점수와 결제 서비스의 차이
9. 상담 전 개인정보 보호 체크

## 톤과 운영 규칙

- 친절하지만 과장하지 않습니다.
- 확정 수치에는 기준 날짜를 함께 표기합니다.
- 광고·제휴 콘텐츠는 첫 화면에서 알아볼 수 있게 표시합니다.
- 고객 후기와 진행 사례는 개인정보를 마스킹하고 사실 확인된 내용만 게시합니다.
- 금융기관으로 오인될 표현과 승인 보장 표현은 사용하지 않습니다.
